# terraform-ecs-module
Forumone's ECS Terraform Module with Traefik and Rsync.net for offsite backups

CI runs in GitHub Actions ([`.github/workflows/ci.yml`](.github/workflows/ci.yml)): formatting, TFLint and terraform-docs checks for each module, ShellCheck/shfmt for the backup scripts, and test builds of the images. Pushes to `main` publish the images to `public.ecr.aws/forumone`.
